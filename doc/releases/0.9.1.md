# qtranslate 0.9.1

Patch release with installer options and documentation updates.

## Downloads

- [Windows installer](https://github.com/youkaicat/QTranslate/releases/download/v0.9.1/qtranslate-0.9.1-win64-setup.exe)
  — per-user installation without administrator rights; Start menu shortcut and autostart by
  default, optional desktop shortcut, uninstaller.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.9.1/qtranslate-0.9.1-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

## Changes since 0.9.0

- The installer now offers separate Start menu, desktop and autostart options.
- Start menu and autostart are enabled by default; the desktop shortcut is optional.
- Autostart is synchronized with the application setting and is removed on uninstall.
- README updated with screenshots, a shorter feature list and Linux build notes.

## Features

- **Ctrl+Q** translates the selected text in a compact window next to the cursor.
- **Ctrl+Shift+Q** translates the selected text and replaces the selection in the active input
  field, which is convenient for replying in chats.
- **Ctrl+W** opens the main window with the selection translated.
- Google Translate (free endpoint or Cloud API) and DeepL (Free/Pro).
- Automatic source language detection, smart switching to the additional language, in-memory
  translation cache and automatic translation while typing.
- System/manual HTTP and SOCKS5 proxies with optional authentication.
- English and Russian interface, autostart, portable INI mode, `--verbose` logging.

Requires Windows 10/11 x64. The text is sent to the selected service and is not written to the log.
