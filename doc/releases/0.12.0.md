# QTranslate 0.12.0

Feature release adding Linux support and optional free web translation services.

## Downloads

Windows 10/11 x64:

- [Installer](https://github.com/youkaicat/QTranslate/releases/download/v0.12.0/qtranslate-0.12.0-win64-setup.exe)
  — installs for the current user; no administrator rights required.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.12.0/qtranslate-0.12.0-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

Linux x86_64, Debian 13 (trixie), glibc 2.38 or newer:

- [Portable archive](https://github.com/youkaicat/QTranslate/releases/download/v0.12.0/qtranslate-0.12.0-linux-x86_64.tar.gz)
  — extract and run `bin/qtranslate`; Qt and the required libraries are included.
- [.deb package](https://github.com/youkaicat/QTranslate/releases/download/v0.12.0/qtranslate_0.12.0_amd64.deb)
  — installs the binary, desktop entry, and icon; depends on the distribution Qt 6 packages.
- [AppImage](https://github.com/youkaicat/QTranslate/releases/download/v0.12.0/qtranslate-0.12.0-x86_64.AppImage)
  — run with `--appimage-extract-and-run` when FUSE is unavailable.

The Linux packages are built in Debian 13 and do not run on Astra Linux 1.8.7 because of the glibc
baseline. Astra Linux is supported through a native build with
`packaging/linux/package.sh --target astra`; see the README for the steps.

## Highlights

- **Linux support.** X11 is the full target: global hotkeys, selection capture, in-place replacement,
  autostart, tray integration, and the desktop entry. Wayland is limited: the `GlobalShortcuts`
  portal where the desktop provides it, the CLI commands, manual copying, and explicit warnings.
- **Linux desktop integration.** Settings and logs follow the XDG directories, autostart uses a
  desktop entry, secrets are stored through libsecret with a `0600` file fallback, and the app is
  shipped with a `.desktop` file and a hicolor icon.
- **CLI and single instance.** `--translate-popup`, `--translate-main`, and `--translate-inplace`
  trigger the three scenarios in a running instance or start one; `--minimized` and `--verbose`
  keep working on both platforms.
- **Free web translation services.** MyMemory (a free no-key API), Mozhi, Yandex web, Bing web, and
  Reverso are optional. They are enabled by **Settings → Services → Allow free web services**,
  may be rate-limited or stop working, and never replace Google/DeepL unless chosen.
- **Fallback service.** One configured free web service retries a failed request once
  (**Settings → Services → Fallback service**). It is off by default, needs the free-services gate,
  retries only on auth, quota, rate-limit, network, or timeout failures, never loops, and shows the
  original error when it also fails.
- **Fullscreen hotkey pause.** Hotkeys are released while a fullscreen application is in the
  foreground, and the behavior can be disabled in **Settings → Hotkeys**.
- Fixed a cache race where a reply that was already running could store a result after the cache
  was cleared by a mode, service, or fallback change.
- Updated all interface translations. The project documentation is now English, with the Russian
  roadmap history kept as an archive.

Requires Windows 10/11 x64, or Linux x86_64 with Debian 13 (trixie) packages as noted above. The
installer is not code-signed yet, so Windows SmartScreen may show a warning. The text being
translated is sent to the selected provider; a local server keeps it on the machine.
