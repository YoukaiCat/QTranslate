# QTranslate 0.11.1

Patch release for Windows with the fullscreen hotkey pause.

## Downloads

- [Installer](https://github.com/youkaicat/QTranslate/releases/download/v0.11.1/qtranslate-0.11.1-win64-setup.exe)
  — installs for the current user; no administrator rights required.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.11.1/qtranslate-0.11.1-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

## Changes

- Hotkeys are released while another application owns a fullscreen window, so games receive
  Ctrl+Q/Ctrl+W; the combinations are registered again after leaving fullscreen.
- A manual **Pause hotkeys** item in the tray menu covers games that are not detected as
  fullscreen. It is not saved between runs.
- **Settings → Hotkeys** has the new `hotkeys/pauseInFullscreen` option, enabled by default.
- The manual pause, the autopause setting and the configured combinations are combined.
- The executable version information is 0.11.1.

Linux support is in development on the main branch and is not part of this Windows release.

Requires Windows 10/11 x64. The installer is not code-signed yet, so Windows SmartScreen may show a
warning. The text being translated is sent to the selected provider; a local server keeps it on the
machine.
