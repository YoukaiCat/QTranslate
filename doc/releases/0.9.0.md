# qtranslate 0.9.0

The first public release candidate of qtranslate, a small tray translator for Windows.

qtranslate lives in the system tray and translates the text selected in any application with a
global hotkey. Version 0.9.0 adds a per-user Windows installer while keeping the portable archive
for users who do not want to install anything or cannot install programs.

## Downloads

- **`qtranslate-0.9.0-win64-setup.exe`** — per-user installer. It does not require administrator
  rights, creates Start menu and optional desktop shortcuts, and adds an uninstaller.
- **`qtranslate-0.9.0-win64.zip`** — portable version. Extract the archive and run
  `bin\qtranslate.exe`; no installation is needed.
- **`SHA256SUMS.txt`** — SHA-256 checksums of both files.

Settings and API keys are stored per user in `%APPDATA%\qtranslate`. The installer does not add
the application to Windows autostart: enable **Start qtranslate when Windows starts** in Settings
if you need it. Uninstalling keeps the settings so a later installation finds them again.

## Features

- **Ctrl+Q** translates the selected text in a compact window next to the cursor.
- **Ctrl+Shift+Q** translates the selected text and replaces the selection in the active input
  field, which is convenient for replying in chats.
- **Ctrl+W** opens the main window with the selection translated.
- Google Translate (free endpoint or Cloud API) and DeepL (Free/Pro).
- Automatic source language detection, smart switching to the additional language, in-memory
  translation cache and automatic translation while typing.
- System/manual HTTP and SOCKS5 proxies with optional authentication.
- English and Russian interface, autostart, portable INI mode, `--verbose` logging.
- The distribution is self-contained: Qt and the MSVC runtime are included, so neither Qt nor the
  Visual C++ redistributable has to be installed.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- An internet connection for translations.

## Known limitations

- Selection capture does not work in windows of processes started as administrator.
- The free Google endpoint can answer `HTTP 429` when it rate-limits a client; wait or use Google
  Cloud/DeepL with an API key.
- The intermediate Ctrl+C used to grab a selection may appear in the Windows clipboard history
  (Win+V); the original clipboard contents are restored.
- The installer is not code-signed yet, so Windows SmartScreen may show a warning.
- Linux support is planned but is not part of this release.

The text being translated is sent to the selected online service (Google or DeepL). qtranslate
does not write the texts to its log.
