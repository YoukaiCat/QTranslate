# QTranslate 0.14.0

Feature release: text checking becomes a standalone feature with two providers, DuckDuckGo and
LibreTranslate join the no-key translation providers, and the opt-in gates are gone.

## Downloads

Windows 10/11 x64:

- [Installer](https://github.com/youkaicat/QTranslate/releases/download/v0.14.0/qtranslate-0.14.0-win64-setup.exe)
  — installs for the current user; no administrator rights required.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.14.0/qtranslate-0.14.0-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

Linux x86_64, Debian 13 (trixie), glibc 2.38 or newer:

- [Portable archive](https://github.com/youkaicat/QTranslate/releases/download/v0.14.0/qtranslate-0.14.0-linux-x86_64.tar.gz)
  — extract and run `bin/qtranslate`; Qt and the required libraries are included.
- [.deb package](https://github.com/youkaicat/QTranslate/releases/download/v0.14.0/qtranslate_0.14.0_amd64.deb)
  — installs the binary, desktop entry, icon and license; depends on the distribution Qt 6 packages.
- [AppImage](https://github.com/youkaicat/QTranslate/releases/download/v0.14.0/qtranslate-0.14.0-x86_64.AppImage)
  — run with `--appimage-extract-and-run` when FUSE is unavailable.

The Linux packages are built in Debian 13 and do not run on Astra Linux 1.8.7 because of the glibc
baseline. Astra Linux is supported through a native build with
`packaging/linux/package.sh --target astra`; see the README for the steps.

## Highlights

- **Text checking is its own feature.** It has a separate non-modal window (tray item **Check text…**
  or the `--proofread-selection` command), its own editor, issue list, Replace/Ignore/Replace all/Copy
  and one-undo-step replacements; the translation window is translation-only again. `proofreading/enabled`
  is the only switch, the second online gate and the check-before-translation flow are gone, and two
  optional hotkeys check a selection in another application (result in a popup, or replace
  immediately).
- **Two checking providers.** LanguageTool (public API or a self-hosted server, no credentials) and
  the OpenAI-compatible provider (**AI** tab: OpenRouter by default, or a local Ollama/llama.cpp
  server). Both feed the same window and popup; an LLM check is one request, edits are parsed locally
  with a diff fallback when the model answers with plain corrected text.
- **DuckDuckGo and LibreTranslate.** Two more translation providers: DuckDuckGo needs no key and
  follows the frontend's token handshake; LibreTranslate works against a server you run or choose,
  without a key when self-hosted. Both appear in the service list, the fallback row and the settings.
- **No more opt-in gates.** Every translation provider is available by default, the fallback service
  moved to the Translation page and the providers have one order.
- **Clearer settings.** The OpenAI-compatible provider moved to its own **AI** tab and is called `AI`
  everywhere in the interface; the two checking hotkeys use the short labels "Check in a popup" and
  "Replace with the corrected text"; the redundant "the text is sent to a third party" sentences are
  gone from the provider hints while the provider-specific warnings stay.
- **Tray icon on Astra Linux.** The icon no longer stays hidden for five seconds after launch: an
  unavailable hotkey is reported in the `--verbose` log and as a hint in the settings dialog instead
  of a tray balloon, which had put the panel's tray item into the attention state.

Requires Windows 10/11 x64, or Linux x86_64 with Debian 13 (trixie) packages as noted above. The
installer is not code-signed yet, so Windows SmartScreen may show a warning. The text being translated
or checked is sent to the selected provider; a local server keeps it on the machine.
