# QTranslate 0.11.0

Feature release focused on AI translation providers, a single DeepL service and the QTranslate
brand.

## Downloads

- [Installer](https://github.com/youkaicat/QTranslate/releases/download/v0.11.0/qtranslate-0.11.0-win64-setup.exe)
  — installs for the current user; no administrator rights required.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.11.0/qtranslate-0.11.0-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

## Highlights

- OpenAI-compatible translation provider with a configurable server URL, API key and model.
  OpenRouter is the default server; `openrouter/free` selects a free model, while paid models are
  also available. OpenRouter requires an API key.
- The same provider works with OpenAI, TeamRouter, LM Studio, llama.cpp and local Ollama. Local
  endpoints need no key.
- The provider settings can load the model list from the endpoint; the check uses the proxy and
  timeout currently entered in the settings dialog.
- DeepL free web is now a mode of the single DeepL service instead of a separate provider. Old
  `deepl-web` settings migrate automatically to `deepl` + `deepl.mode=free-web`.
- The application is branded **QTranslate** in window titles, tray, User-Agent, executable version
  information and installer shortcuts/ProductName.
- Fixed the proxy test false failure caused by a `404` response from the old test URL.
- The Services settings page scrolls, so long hints and the provider list are not clipped at high
  DPI scaling.
- Updated all interface translations.

Requires Windows 10/11 x64. The installer is not code-signed yet, so Windows SmartScreen may show a
warning. The text being translated is sent to the selected provider; a local server keeps it on the
machine.
