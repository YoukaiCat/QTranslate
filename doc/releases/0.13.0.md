# QTranslate 0.13.0

Feature release adding opt-in proofreading with LanguageTool, a native Debian package, and the
GPL-3.0-or-later license.

## Downloads

Windows 10/11 x64:

- [Installer](https://github.com/youkaicat/QTranslate/releases/download/v0.13.0/qtranslate-0.13.0-win64-setup.exe)
  — installs for the current user; no administrator rights required.
- [Portable ZIP](https://github.com/youkaicat/QTranslate/releases/download/v0.13.0/qtranslate-0.13.0-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

Linux x86_64, Debian 13 (trixie), glibc 2.38 or newer:

- [Portable archive](https://github.com/youkaicat/QTranslate/releases/download/v0.13.0/qtranslate-0.13.0-linux-x86_64.tar.gz)
  — extract and run `bin/qtranslate`; Qt and the required libraries are included.
- [.deb package](https://github.com/youkaicat/QTranslate/releases/download/v0.13.0/qtranslate_0.13.0_amd64.deb)
  — installs the binary, desktop entry, icon and license; depends on the distribution Qt 6 packages.
- [AppImage](https://github.com/youkaicat/QTranslate/releases/download/v0.13.0/qtranslate-0.13.0-x86_64.AppImage)
  — run with `--appimage-extract-and-run` when FUSE is unavailable.

The Linux packages are built in Debian 13 and do not run on Astra Linux 1.8.7 because of the glibc
baseline. Astra Linux is supported through a native build with
`packaging/linux/package.sh --target astra`; see the README for the steps.

## Highlights

- **Proofreading with LanguageTool.** A new **Text checking** tab sends the source text to the
  public `api.languagetool.org` or a self-hosted LanguageTool and shows issues in the main window.
  The feature is opt-in: **Settings → Text checking → Allow online text checking** defaults to
  off, the checked text goes to the chosen server, and no API key or username is sent. The main
  window has **Check**, issue highlighting, Replace/Ignore, Replace all with a preview, Copy
  corrected text, one-undo-step replacements, and optional check-before-translation.
- **Check the selection in another application.** A separate hotkey (empty by default) and
  `--proofread-selection` open a non-activating confirmation popup next to the selection; Replace
  selection applies the corrections, Copy puts them on the clipboard, and a foreground change or a
  failed paste falls back to the clipboard.
- **Native Debian package.** The repository is now a native Debian source package: a top-level
  `debian/` with `dpkg-buildpackage`, a clean-copy build, a source-package format of
  `3.0 (native)`, and a package gate that checks the contents, dependencies and install. The
  release `.deb` is built by `dpkg-buildpackage`, not staged by hand.
- **GPL-3.0-or-later.** The project is free software under the GNU General Public License version
  3 or later. The full text is in `LICENSE` and ships in the bundles and the Debian package.

Requires Windows 10/11 x64, or Linux x86_64 with Debian 13 (trixie) packages as noted above. The
installer is not code-signed yet, so Windows SmartScreen may show a warning. The text being
translated or checked is sent to the selected provider; a local server keeps it on the machine.
