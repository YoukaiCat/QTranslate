# qtranslate 0.10.0

Feature release with a free DeepL option, a localized interface and a smaller distribution.

## Downloads

- [Windows installer](https://github.com/youkaicat/qtranslate/releases/download/v0.10.0/qtranslate-0.10.0-win64-setup.exe)
  — per-user installation without administrator rights; Start menu shortcut and autostart by
  default, optional desktop shortcut, uninstaller.
- [Portable ZIP](https://github.com/youkaicat/qtranslate/releases/download/v0.10.0/qtranslate-0.10.0-win64.zip)
  — extract and run `bin\qtranslate.exe`; no installation required.

## Changes since 0.9.1

- Added **DeepL free web**: an unofficial endpoint without an API key, available as a separate
  service next to Google Translate and DeepL. It may be rate-limited or stop working; the official
  DeepL API remains more reliable.
- The interface is translated into 15 languages: English, Russian, Spanish, German, French,
  Portuguese (Brazil), Italian, Polish, Ukrainian, Turkish, Chinese (Simplified), Japanese,
  Korean, Arabic and Hindi. Arabic uses a right-to-left layout.
- Qt standard dialogs are localized for the supported languages. Hindi standard dialogs remain in
  English because Qt 6.12 has no Hindi catalog.
- The distribution is smaller: the unused software OpenGL rasterizer is no longer bundled.
- Long language names no longer clip in the language selector.
- Added documentation for code signing, free web endpoints, local offline translation,
  proofreading and LLM actions.

## Features

- **Ctrl+Q** translates the selected text in a compact window next to the cursor.
- **Ctrl+Shift+Q** translates the selected text and replaces the selection in the active input
  field, which is convenient for replying in chats.
- **Ctrl+W** opens the main window with the selection translated.
- Google Translate (free endpoint or Cloud API), DeepL (Developer/Growth) and DeepL free web
  (unofficial, no API key).
- Automatic source language detection, smart switching to the additional language, in-memory
  translation cache and automatic translation while typing.
- System/manual HTTP and SOCKS5 proxies with optional authentication.
- Autostart and portable INI mode.

Requires Windows 10/11 x64. The text is sent to the selected service and is not written to the log.
The installer is not code-signed yet, so Windows SmartScreen may show a warning.
